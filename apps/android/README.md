# Amiscara Agents for Android

Kotlin and Jetpack Compose app for phones and tablets (Android 10 and
newer). It calls the same Rust core as the Apple apps: `herdr-ffi` built as
`libherdr_ffi.so` per ABI, with Kotlin bindings generated by UniFFI (package
`net.staude.amiscara.agents.core`, through JNA). Plan and phases: #179.

## Setup

Needs Android Studio (SDK and its JDK, or any JDK 17), the NDK named by
`ndkVersion` in `app/build.gradle.kts`, `cargo-ndk` and the Rust targets:

```sh
sdkmanager "ndk;29.0.14206865" "platforms;android-37.0"   # or SDK Manager
rustup target add aarch64-linux-android x86_64-linux-android
cargo install cargo-ndk --locked
```

`./setup.sh` in the repository root does the last two when it finds an
Android SDK.

## Build and run

```sh
cd apps/android
./gradlew assembleDebug            # also builds the Rust core
./gradlew lintDebug
../../scripts/install-android.sh   # build, install and launch (adb)
```

The task `buildRustCore` runs `scripts/build-android-ffi.sh` before every
build and writes the libraries and bindings to `app/build/generated/rust`
(not checked in). Cargo only rebuilds what changed. ABIs: `arm64-v8a` for
phones, `x86_64` for the emulator; the NDK links them with 16 KB pages, as
Google Play requires.

Opening `apps/android` in Android Studio works the same way.

## Emulator

The AVD `Pixel_9` (Android 17, arm64) runs on work, also without a window:

```sh
~/Library/Android/sdk/emulator/emulator -avd Pixel_9 -no-window -no-audio &
scripts/install-android.sh emulator-5554
```
