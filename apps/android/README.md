# Amiscara Agents for Android

Kotlin and Jetpack Compose app for phones and tablets (Android 10 and
newer). It calls the same Rust core as the Apple apps: `herdr-ffi` built as
`libherdr_ffi.so` per ABI, with Kotlin bindings generated by UniFFI (package
`net.staude.amiscara.agents.core`, through JNA). Plan and phases: #179.

## Setup

Needs Android Studio (SDK and its JDK, or any JDK 17), the NDK named by
`ndkVersion` in `app/build.gradle.kts`, `cargo-ndk` and the Rust targets:

```sh
sdkmanager "ndk;29.0.14206865" "platforms;android-37.0"   # or SDK Manager
rustup target add aarch64-linux-android x86_64-linux-android
cargo install cargo-ndk --locked
```

`./setup.sh` in the repository root does the last two when it finds an
Android SDK.

## Languages

English is the default (`res/values/strings.xml`), so it is also the
fallback for languages without a translation; German is in
`res/values-de/strings.xml` (#207). Every string a user sees comes from the
resources, also the ones built in model code (`model/Texts.kt`). A new
language is a new `values-<code>/strings.xml` plus an entry in
`res/xml/locales_config.xml`. Messages from the Rust core (e.g. the checks
of an add-host link) are still German for now.

## Build and run

```sh
cd apps/android
./gradlew assembleDebug            # also builds the Rust core
./gradlew lintDebug
./gradlew testDebugUnitTest        # unit tests on the JVM
../../scripts/install-android.sh   # build, install and launch (adb)
```

The task `buildRustCore` runs `scripts/build-android-ffi.sh` before every
build and writes the libraries and bindings to `app/build/generated/rust`
(not checked in). Cargo only rebuilds what changed. ABIs: `arm64-v8a` for
phones, `x86_64` for the emulator; the NDK links them with 16 KB pages, as
Google Play requires.

Opening `apps/android` in Android Studio works the same way.

## Hosts and keys

- Hosts: `hosts.json` in the app's files, same fields as `HostConfig` of the
  other apps. Android only knows SSH with a key of its own (no agent, no
  local socket).
- Private keys: generated by the core, sealed with an AES key of the Android
  Keystore, in `noBackupFilesDir/keys`. No cloud backup or device transfer
  (`data_extraction_rules.xml`).
- Add a host by hand, by QR code (CameraX and ZXing, no Google Play
  Services) or by link. A scanned or pasted link pins its host key; a link
  opened from elsewhere (`amiscara-agents://add-host?...`) does not, and a
  link never replaces a host key another host at that address trusts.
- Android 17 blocks private addresses (home network, VPN, the emulator's
  `10.0.2.2`) for apps that target it: the app asks for
  `ACCESS_LOCAL_NETWORK` ("Geräte in der Nähe") once there is a host, and
  shows a hint while it is missing. Without it, sessions hang in
  "Verbinde …".
- Rust panics go to logcat with the tag `herdr-ffi`.

## Main view

- Start screen: per host its state, spaces (name groups, worktrees indented,
  branch below) and agents, most urgent first. From 700 dp width (tablet,
  foldable, phone in landscape) the selected space shows on the right.
- A space: tabs, the selected pane's terminal and the input bar. A split
  tab shows its panes as herdr draws them on a wide screen (the selected
  one live, the others read slowly); on a phone chips pick the pane.
- Terminal: lines keep the pane's width and scroll both ways, pinch changes
  the font size (8 to 28), older history loads in steps up to 1000 lines,
  search marks hits, web addresses open in the browser. With "Vollbild-Agenten scrollen" on, a Claude pane pages through its own view and fetches its transcript. With "Zeilen umbrechen (experimentell)" on, long lines wrap at the screen width instead (#191). Color schemes and minimum contrast as in the other
  apps (`ui/TerminalTheme.kt`).
- Input bar: answers 1, 2, 3, Bestätigen, Abbrechen while an agent waits,
  key bar and quick replies in one row, photos and files as attachments
  (needs "Dateien hochladen"), live mode for slash commands. A prompt goes
  to an agent with `agent.prompt`, to a shell as text plus Enter.

## Managing and settings

- Host menu (⋮ in the sidebar): details, reconnect, new space. A long press
  on a space renames it, makes a worktree from its repository or closes it
  (with its linked worktrees); on an agent it names the agent.
- Space menu (⋮ top right): new tab, start an agent in a shell pane, name
  the agent, the Claude Code conversation (needs SFTP for the key), rename
  or close tab and space, font size. New space, tab and worktree can start
  an agent right away; the dialogs remember the last choice.
- Quick switcher (🔍 or Ctrl+K): spaces and agents on all hosts, matched
  like the other apps.
- Settings: terminal light/dark, color scheme, minimum contrast, line wrapping, font size,
  quick replies.

## Notifications and standby

- Notifications when an agent starts waiting or is done (texts as in the
  other apps), one per pane; not for the pane on screen. A tap opens the
  pane. A waiting agent's notification has the buttons 1, 2 and 3 (Android
  shows three at most); they send the key also when the app is closed, after
  unlocking. Off per host in the host editor. Android 13 and newer ask for
  the permission once there is a host.
- There is no push: without the standby, notifications only come while
  Android lets the app run. "Bereitschaft" (settings, Quick Settings tile)
  keeps the process and its sessions alive in a foreground service of type
  `specialUse` with an ongoing notification (hosts connected, agents
  waiting, "Beenden"). It comes back after an app update and, if wanted,
  after the device starts. The settings point to the battery optimization
  while it applies.
- Code: `standby/` (`Notifier`, `StandbyService`, `AnswerReceiver`,
  `BootReceiver`, `StandbyTile`).

## Widget

Glance widget "Agents" like the one of the Apple apps: small, the number
of waiting agents and working ones (a tap opens the first waiting agent);
from about three cells wide, the agents of all hosts with their state, as
many as fit, each opening its pane. It shows the last state the app saw
("Stand 14:05"), live while the app or the standby runs; the snapshot is
kept in the preferences for after the process ended (`widget/`).

## Release

```sh
../../scripts/android-upload-key.sh         # once: upload key, password in the Keychain
../../scripts/android-release.sh 0.2.0      # per upload: versionCode + 1, signed .aab, tag
```

`version.properties` holds `versionName` and `versionCode`. The release
build is signed only with `keystore.properties` (not checked in) and the
password in `AMISCARA_UPLOAD_KEY_PASSWORD`, which the release script takes
from the Keychain. Google keeps the app signing key (Play App Signing).
Play Console texts and steps: `docs/play-store.md`.

Keyboard (hardware keyboard on a tablet or phone):

| Keys | Action |
|---|---|
| Ctrl+K | Quick switcher |
| Ctrl+1 … 9 | Space by position on the current host |
| Ctrl+Shift+[ / ], Ctrl+PageUp/Down | Previous / next tab |
| Ctrl+F | Search in the pane |
| Ctrl+plus / minus / 0 | Terminal font size |
| Ctrl+Alt+1 … 3 | Answer a waiting agent |
| Ctrl+Alt+arrows, Ctrl+., Ctrl+Shift+Enter | Arrow keys, Esc, Enter to the pane |

Ctrl+Alt shortcuts are ignored for keys typed with AltGr.

## Emulator

An AVD such as `Pixel_9` (Android 17, arm64) also runs without a window:

```sh
~/Library/Android/sdk/emulator/emulator -avd Pixel_9 -no-window -no-audio &
scripts/install-android.sh emulator-5554
```

The emulator reaches this Mac as `10.0.2.2`. For a connection test use the
separate session (`herdr --session herdr-remote-test server`) and its socket
`/Users/<user>/.config/herdr/sessions/herdr-remote-test/herdr.sock`.
