# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the
work. Harassment, insults and personal attacks are not tolerated in
issues, pull requests or any other project space.

Report unacceptable behavior privately to the maintainer through a
[security advisory](https://github.com/staude/amiscara-agents/security/advisories/new)
or the contact on the maintainer's GitHub profile. Reports are handled
confidentially; the maintainer may remove content or block participants
who break these rules.
